# Octop 飞书通俗版发布规则

> 本文是 **Octop 项目专属**的通俗版口径，接在通用规则
> （`/opt/ob-vault/docs/feishu-publish-rules.md`）后面，一起喂给写稿模型。
> 两者冲突时，**本文件优先**。

## 一、这篇文档写什么

**只写两件事：**

1. **素材管理**——把本机的商品图片整理成可用的素材库：目录导入、AI 识别分组、
   坏图/差图/重复图进隔离区、挑选素材。
2. **多平台视频文件生成**——从素材到成片的流程：产品视频向导、分镜、配音配乐、
   导出成各平台画幅的视频文件。

面向的读者是**内容创作者与电商运营**，以及**帮客户装客户端做交付的人**。

## 二、范围之外的一律不写

下面这些是 Octop 确实有的功能，但**不属于这篇文档的范围**，写进来就是冗余：

- IM 通道接入（飞书 / 钉钉 / QQ / 微信 / 企业微信 / Telegram / Discord）
- 命令行、HTTP 接口、ACP、连接器、插件、专家市场、专家/团队/云端分组
- 团队与权限、页签勾选、多用户隔离、Web 控制台本身的用法
- 服务端部署运维（`pip install` 起服务、数据库、迁移）

也不写这些内部说法：IM 通道、ACP、AgentTeams、多专家、模型路由、网关、知识库 RAG。

**只写「桌面客户端上做什么」**。要讲服务端托管的界面功能时，写成「登录后就能用的
界面功能」，不展开它的后台实现。

## 三、置顶区（照抄这个骨架，不要自己发挥）

```markdown
# Octop 桌面客户端

<一句话简介：这是什么、给谁用、能做成什么事>

**下载：** [Gitee 发布页](https://gitee.com/webheat/octop_client/releases) —— 绿色版压缩包，解压即用

**代码：** [Gitee 客户端仓库](https://gitee.com/webheat/octop_client)
```

- 简介两三句，不出现「平台」「Agent」「自托管」「多用户」这些内部说法；
  **第一句不要重复软件名称**，直接说它是什么。
- 「下载」与「代码」**各占一段**（中间空一行），不要挤成同一段。
- 下载行是**可点击的链接**，读者点它就是为了拿客户端——这是本文最重要的一行。
- 版本号不写死在正文里：客户端版本以 Gitee 发布页展示的信息为准（仓库里版本号分叉，
  写死就是写错）。

## 四、多平台输出怎么写

- 一句话说清：导出时可以按目标平台选画幅，**同一个素材出多份不同规格的视频文件**。
- 可选的平台：抖音、小红书、视频号、快手、B 站、TikTok、Instagram、YouTube。
- 画幅规格三种：竖版 1080×1920、横版 1920×1080、方形 1080×1080。
- **不做平台自动上传**：导出的是视频文件，发布到平台仍要用户自己操作。
  不要写成「一键发到抖音」。

## 五、术语对照

| 说人话 | 不要写 |
|---|---|
| 视频组件 / 渲染引擎 | video-runtime、Remotion、Chromium、node_modules |
| 分镜 | storyboard package、storyboard-package |
| 素材库 | product-library 目录、product_library 表 |
| AI 分组 / 识别 | 多模态推理、embedding、模型调用链 |
| 配音 | TTS、SAPI、MiniMax |
| 绿色版 | 免安装包、slim/full 形态、内核模式 |

## 六、事实边界

- 桌面客户端只提供 **Windows x64**；macOS 与 Linux 版未发布。
- 视频组件**不随安装包分发**：界面「视频环境」页点「一键安装」按需下载，
  没装时**其余功能照常用**，只是本机出不了片。
- 素材本体与分类结果**存在本机**，服务端只在 AI 识别那一刻临时接收图片。
- 登录走微信开放平台扫码，客户端不要求用户填服务器地址。
- 本机出片**不需要安装 Python**。
