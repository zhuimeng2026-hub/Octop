# 一条视频里混用多个产品分类的画面

> 面向使用者：用 Octop 制作商品短视频的运营、买手和内容创作者。
> 适用位置：产品视频制作向导 → 第一步「选择产品」。

## 这是什么

以前，一条商品视频只能从一个产品下面挑画面。想把另一个分类里的镜头也放进同一条视频，
就得先做一条、再回来改，做不成一次成片。

现在，你可以在第一步里勾选**多个产品分类**，把它们的画面合并到同一批画面里，
一次生成方案、一次出片。成片里的标题、卖点和产品信息，仍然以你指定的那个**主推产品**为准。

打个比方：主推产品是这次要推销的主角，其他分类是"顺带出镜"的补充画面。

## 开始之前先确认

| 你要做的事 | 在哪里做 |
| --- | --- |
| 建产品、写产品名、型号、分类、卖点 | 产品素材库 → 添加产品 |
| 上传图片和视频 | 产品素材库 → 对应产品 → 上传 |
| 把素材标记为「画面素材」 | 上传时或素材列表里设置用途 |
| 停用不想再用的素材 | 素材列表里关掉它 |

三条硬性前提，缺一个素材就不会出现在画面列表里：

1. 素材已经归到某个产品下面；
2. 素材的用途是**画面素材**（"理解参考"和"风格参考"只给 AI 看，不会上片）；
3. 素材没有被停用。

## 制作步骤

### 第一步：选择产品与画面素材

这一屏上有三个东西，从上往下看：

**「产品」下拉框 —— 主推产品。**
它决定这条视频的主角：标题、卖点、给 AI 的产品事实都取自它。
换了主推产品，等于重开一条方案：原来的画面选择、还没上传完的素材、已经写好的制作要求都会清空，
新主推产品的画面重新勾上。

**「素材分类」多选框 —— 画面从哪来。**
- 里面每一项写着「产品名 · 分类名」，主推产品默认已经在里面，而且**不能取消**。
- 选中一个分类，它的画面就会合并进下面的画面列表。
- 可以随时追加或取消其他分类。

**「本次可用素材」—— 合并后的画面。**
- 来自不同产品的画面会带上它属于哪个产品，方便你认出同名文件。
- 新追加的分类，画面默认全部选中。已有分类保留原来的勾选状态；点一下卡片可以取消勾选，再点一下恢复。
- 「补充素材」可以临时补拍：补进去的文件归到**当前主推产品**下面，不会混进别的分类，也不会打乱你已经选好的画面。

### 第二步：制作要求

写清楚视频用途、目标平台、语言、画幅、每张画面停留几秒、要不要带上产品卖点。
默认的竖屏、单张 4 秒通常可以直接用。

### 第三步：AI 视频方案

点「生成 AI 视频方案」，AI 按你勾选的画面排出分镜脚本：片头、逐个画面、片尾。

### 第四步：确认调整

逐个镜头核对画面和文案，可以改单个镜头的时长、换画面、调顺序。改完记得保存并确认。

### 第五步：下载制作

确认后的方案可以下载制作包，在本机渲染成 MP4；桌面端也可以直接在本机出片。

## 什么是「成片清单」

一旦你点了生成，这份方案里的画面就被**固定下来**了——用的是哪几张图、来自哪个产品、
每张的时长和用途，全部锁定。界面上会提示你「项目已建立快照」，说的就是这件事。之后：

- 你再改产品名、改卖点，不影响已经做好的方案；
- 你停用或者删掉产品里的素材，不影响已经做好的方案；
- 已经做好的方案**不能再加画面**。想加，回产品素材库另建一条方案。

这是有意为之：已经确认的方案就该保持原样，避免改到一半发现成片和当时想的不一样。

## 你的素材只有你能用

- 一条方案里的所有画面，都必须来自你自己的账号。
- 别人的素材哪怕你已经知道编号，也塞不进你的方案。
- 反过来，你的素材也不会跑进别人的方案里。

## 常见问题

**Q：加了一个分类，画面一个都没多？**
A：那个分类下面可能还没有"可用于画面"的图片或视频。资料类的素材、被停用的素材都不会进画面列表。
先回产品素材库确认这个产品下确实有标了「画面素材」的文件。

**Q：为什么主推产品移不掉？**
A：它是这条视频的主角，标题和卖点都要从它这里取。去掉它，方案就没有主角了。

**Q：我切换了主推产品，之前选的画面全没了？**
A：会清空，这是设计如此。切换主推产品就是重开一条方案，新主推产品的画面会重新勾上。

**Q：我补传的图片算在哪个分类里？**
A：算在当前主推产品下面。想让它出现在别的分类下，要在那个产品下单独上传。

**Q：能不能把两个账号的素材混在一条视频里？**
A：不能，也不应该。

**Q：同一份选择点了两次生成，会得到两条方案吗？**
A：会。两份内容一致，但互相独立，改一份不影响另一份。

## 已知限制

- **方案建立后不能再加画面。** 要加只能另建一条方案。
- **单条视频有时长上限。** 所有镜头加起来最多 180 秒；AI 排出的镜头数量也有上限。
  素材挑得太多时，超出部分不会出现在分镜里。

## 界面对照

| 界面上看到的 | 指的是 |
| --- | --- |
| 产品 | 你要推销的那件商品，可以有多个 |
| 分类 | 商品的品类标签，比如"夏季上新""清仓款" |
| 素材分类（多选） | 这次视频允许取用画面的产品分类，可以多选 |
| 画面素材 | 会真正出现在成片里的图片或视频 |
| 理解参考 / 风格参考 | 只给 AI 看、不上片的文件 |
| 本次可用素材 | 所有已选分类合并后的画面 |
| 项目已建立快照（界面提示） | 这条方案已经定稿，画面清单固定 |
| 成片清单 | 方案里固定下来的那份画面名单 |
| 补充素材 | 制作过程中临时补传的画面，归到主推产品 |
