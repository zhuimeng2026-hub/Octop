## 全局布局

- 复用现有 Dashboard 的登录、`PageShell`、侧边栏、Ant Design 组件、Lucide 图标和 i18next。新页面挂在产品素材库下，侧栏仍选中产品素材库。
- 主页面入口：`/product-library/video-wizard`。已有项目可从产品库继续进入，项目 ID 用于读取服务端草稿，权限由已有登录接口校验。
- 五步为「选择产品 → 制作要求 → AI 视频方案 → 确认调整 → 下载制作」。已完成步骤可返回，后续步骤受有效数据约束，操作中不允许跨步骤产生竞态。
- 使用主题变量 `--fn-*`，继承浅色、深色及调色板。主色默认玫瑰色；标题、正文、边框与背景跟随现有主题，不硬编码一套独立配色。
- 桌面镜头卡片三列，中等窗口两列，小窗口一列；步骤横向保持清晰或可横向滚动，表单与操作栏允许换行，不产生页面级横向溢出。
- 每一步只有一个显著主操作。次要操作采用普通按钮或文字链接；输入须有可读标签、键盘焦点和清晰禁用状态。

## 五步交互

### 1. 选择产品

只列出当前登录用户的产品与素材。选一个商品后展示可用图片、视频及已确认卖点，支持选择本次素材、上传补充素材和保存卖点。产品说明作为本次制作要求补充，不虚构后台不存在的商品字段。参考文档不作为可播放镜头使用。

没有产品时提供前往产品素材库的入口；素材读取失败时明确重试，不将错误展示为空库。上传和修改事实在创建项目快照前完成，旧项目继续使用原快照。更换商品不得把上一个商品的异步结果或素材混入新商品。

### 2. 制作要求

使用业务用语：用途、目标客户、发布平台、语言、目标时长、风格、补充要求。低频选项可收起，提供合理默认值。用途、受众、平台、风格及补充说明合成为自然语言要求，不向普通用户展示其内部结构。

后台目前只支持中文和英文，以及竖屏、横屏、方形三种画幅。目标时长作为意图与素材时长建议传递；界面明确实际时长以分镜合计为准，不承诺平台专用尺寸或精确总时长。自然语言请求总长不超过接口的 3000 字符限制。

### 3. AI 视频方案

通过已有接口创建不可变产品快照，再由用户主动发起一次 AI 分镜生成。生成中显示等待状态；失败可重试，并保留先前可用方案。不以模板结果冒充 AI 成功，不修改模型配置。

### 4. 确认调整

按顺序展示镜头卡片。每张卡片包含镜头类型/序号、已授权素材或文字内容、字幕与时长。文字、卖点列表、图片、视频、片尾等现有镜头类型均可编辑其实际文案字段，避免保存后丢字段。素材替换限定在当前项目快照、合法用途及匹配媒体类型内。

显示镜头实际时长之和；每镜头 0.25–15 秒、总计不超过 180 秒。保存失败保留编辑，提供明确重试；只有服务端成功响应才能称为已保存。用户可重新生成或保存当前修改；确认需将完整草稿成功保存为已确认。

画面标注为「镜头示意」，不显示假播放按钮。选定视觉稿中的手串照片仅是示例，生产页面必须显示用户产品库中的素材。

### 5. 下载制作

只有服务端确认成功且当前无未保存修改时才能导出。调用确认分镜专用 ZIP 接口，不回退到旧模板包。下载失败可重试，不显示成功。

展示简洁本机操作：完整解压 ZIP → Windows 双击 `preview.cmd` / macOS 双击 `preview.command` → Studio 中预览并点击 Render 输出 MP4，也可使用包内的 render 启动器。首次运行需要 Node.js 22+ 和网络连接。制作包是交付物，MP4 在本机生成。

## 状态、返回与恢复

| 状态          | 界面行为                                   |
| ------------- | ------------------------------------------ |
| 未保存/有修改 | 保留输入，提示保存；不得显示可导出         |
| 保存中        | 禁用冲突操作，维持当前编辑内容             |
| AI 生成中     | 显示加载与说明，避免重复提交               |
| 失败          | 显示具体操作的友好错误与重试，保留已有数据 |
| 待确认        | 镜头方案可编辑，确认前无法导出             |
| 可导出        | 已确认分镜可下载 ZIP，返回编辑后需重新确认 |

前后切换保留当前输入；已有项目从服务器读取草稿与确认状态。若持久化浏览器制作进度，必须按用户 ID 隔离，并在切换账号时清理页面内旧数据。下载素材通过既有认证请求获取 blob，离开页面或切换素材时回收对象 URL。

制作要求的结构化业务字段复用现有 `request.instructions` 字符串保存，以 `OCTOP_VIDEO_BRIEF_V1:` 版本前缀编码，读取时恢复到对应表单。此内部格式不展示在普通用户界面；旧版无前缀草稿仍将原文恢复到补充说明。编码超过后台的 3000 字符限制时，界面提示精简要求，不截断保存内容。

## API 映射

所有路径位于现有 `/api/product-library` 下，由 Dashboard 请求封装处理登录与部署前缀。

| 操作             | 已有接口                                                      |
| ---------------- | ------------------------------------------------------------- |
| 选择产品         | `GET /products`                                               |
| 读取、上传素材   | `GET/POST /products/{product_id}/assets`                      |
| 保存产品事实     | `PATCH /products/{product_id}`                                |
| 获取授权素材预览 | `GET /assets/{asset_id}/download`                             |
| 创建/列出项目    | `POST/GET /projects`                                          |
| 生成方案         | `POST /projects/{project_id}/generate-storyboard`             |
| 读取草稿         | `GET /projects/{project_id}/storyboard`                       |
| 保存/确认草稿    | `PUT /projects/{project_id}/storyboard`，`confirmed` 表达确认 |
| 下载已确认方案   | `GET /projects/{project_id}/storyboard-package`               |

## 验收与边界

按本次任务约定，仅运行前端 TypeScript、生产构建及相关组件基础测试；不运行 `make all` 或后端全量测试。浏览器截图需注明是否采用模拟 API 数据，不将模拟请求结果当作真实 LLM、权限隔离或 MP4 渲染验收。

本次不新增后端接口，不变更认证/SSO，不实现在线 Remotion Player、多轨剪辑、自动配音、自动发布或桌面 M1 集成。真实模型可用性、服务端权限与本机完整渲染仍需在部署环境单独验收。
