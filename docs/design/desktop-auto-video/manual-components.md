# 视频制作环境：轻量客户端与独立组件

本次选择：客户端安装包保持轻量，首次使用先检测；制作环境缺失时，由客户手动安装独立的“Octop 视频制作组件”，再回到客户端重新检测。不让客户端自动下载安装器，不要求客户分别配置 Node、npm 或 Remotion。

## 客户操作

1. 安装并打开 Octop 客户端，正常登录并进入“制作产品视频”。缺少制作环境不影响登录、产品库和方案编辑。
2. 页面提示“需要安装视频制作组件”时，获取并运行独立组件安装包。有发布下载地址时页面提供下载入口；尚未配置地址时，联系管理员获取安装包。
3. 按默认设置完成组件安装，再回到 Octop 点击“重新检测”。组件已安装但尚未验证时，点击“验证制作环境”。
4. 客户端通过一个极短的本机测试视频确认可用，显示“本机制作已就绪”后，即可确认方案并制作正式视频。

安装和验证不会调用 AI，也不会消耗一次分镜生成。重新打开历史方案或完成环境验证，都不会自动开始制作历史视频。

## 组件与客户端分开交付

- 连接远程服务器的 Windows 客户端只包含桌面壳、登录/工作台所需文件和环境检测能力，不携带本地 Python 后端或视频运行时。
- 独立视频组件包含受信任的固定模板、Node、锁定的 Remotion 依赖及渲染浏览器。其体积单独计算，不进入客户端安装包。
- 默认组件目录是 `%LOCALAPPDATA%\Octop\video-runtime`，按当前 Windows 用户安装，不更改系统 PATH。
- 原有显式开发路径和旧版 exe 旁的 `video-runtime` 保留兼容；普通浏览器仍走制作包下载流程。
- 下载地址在桌面构建时配置。没有发布组件安装包前，不显示一个无法使用的下载按钮。

## 检测结果

| 状态 | 处理方式 |
| --- | --- |
| 未安装制作组件 | 获取并手动安装独立组件，然后重新检测 |
| 组件已安装、尚未验证 | 验证制作环境，执行极短本机出片测试 |
| 检测中 / 验证中 | 等待当前阶段完成，可继续编辑方案 |
| 本机制作已就绪 | 可以确认方案并开始制作 |
| 组件损坏或测试失败 | 按页面提示重新安装组件或联系管理员；不要求重装轻量客户端 |
