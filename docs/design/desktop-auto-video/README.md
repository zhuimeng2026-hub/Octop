# 桌面端自动制作视频

视觉基准：[安心制作页](selected-concept.png)。沿用现有横向五步向导，前四步仍是选择产品、制作要求、AI 方案、确认调整；桌面端第五步变为“制作视频”。

## 交互规范

用户点击“确认并制作”后，客户端自动准备素材、制作画面并保存制作结果。页面展示当前真实阶段；只有可测量的阶段显示百分比。产品图片标注“封面示意”，完成后才显示实际视频播放器。

制作中可点击“后台制作”返回产品库，切换页面或最小化客户端不影响任务。离开制作页后提供简洁的全局制作状态入口。取消停止本次任务；失败、取消或退出中断后可重试，重试复用已确认方案，不重新调用 AI。

完成后主操作为“保存视频”，打开系统另存为对话框。取消另存为不会删除制作结果。再次打开同一方案优先展示已有结果，不因浏览历史自动开始制作。方案有变化时需重新确认。

关闭窗口按现有设置最小化到托盘时可继续制作；真正退出客户端会中断任务，重启后保留可重试状态。MVP 同时制作一个视频；忙碌时提示先处理当前任务。

## 状态文案

| 状态 | 用户反馈 | 主要操作 |
| --- | --- | --- |
| 准备中、下载中 | 准备素材，必要时显示准备进度 | 后台制作 |
| 渲染中 | 制作画面，显示实际进度 | 后台制作 |
| 写入中 | 正在保存制作结果 | 等待完成 |
| 完成 | 视频已制作完成，真实播放器 | 保存视频 |
| 失败 | 可理解的失败原因，保留已确认方案 | 重新制作 |
| 已取消 | 制作已取消 | 重新制作 |
| 退出中断 | 上次制作已中断 | 重新制作 |

普通桌面用户不需要理解 ZIP、JSON、命令或渲染引擎。普通浏览器保留原有制作包下载功能。

## 实现边界

- 复用现有登录、用户产品库、分镜草稿读取与确认、制作包导出接口，不新增服务器渲染服务。
- 只有已确认方案才能制作；客户端通过服务器认证当前用户，再读取该用户有权访问的项目。
- 本地只使用客户端随附的受信任制作程序。服务器压缩包只提供经过校验的方案和素材，不执行其中的程序。
- 当前交付优先验证 Windows。安装包必须包含配套的 `video-runtime`；单独更新服务器 Dashboard 不会给旧客户端增加本机制作能力。
- 原始桥接与工作进程协议见 [contract.md](contract.md)。

## 验证范围

按用户要求，只运行相关前端基础测试、TypeScript 与生产构建、本功能 Go 测试及短视频实际渲染。不会运行仓库全量测试或全平台打包矩阵。实测结果与尚未验证部分记录在本目录的验收文档中。
