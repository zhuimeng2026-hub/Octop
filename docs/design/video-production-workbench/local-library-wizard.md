> 状态：**已实现**（实现基线：`develop` 上的 `d8988e10`；2026-11-24 复核）
> 目标读者：桌面端 / 前端 / 后端 / 测试
> 适用范围：桌面客户端的**本机素材库**与**本机视频向导**（本机渲染路径）。
> 不适用范围：服务端产品素材库（Web 路径）—— 跨产品分类选材见
> [跨产品分类选材](../../product-video-multi-category-materials.md)，
> 目录批量导入与大图体积处理见 [产品素材库批量导入](../../product-image-batch-import.md)。
> 兄弟文档：工作台升级规格（引导模式 / 精细工作台 / 多平台输出）见 [PRD.md](./PRD.md)。
> 素材与数据所有权决策见 [平台 PRD §3.7](../../PRD.md)。

## 1. 产品目标与入口

- **整理存量图片**。用 AI 识别类别、标签和描述，形成可复核的产品分组。归档后的素材可以浏览、选用，并作为智能分镜的候选素材。
- **引导完成视频制作**。保留完整制作流程，每步说明要完成的操作。常用设置提供默认值，用户也可以逐步修改。
- **桌面导航**。左栏提供「视频制作」「本机素材库」「环境检测」。素材库是独立入口，用户无需先创建视频项目。桌面精简模式默认打开视频制作。

## 2. 本机素材导入、识别和归档

1. 用户从本机选择目录导入图片。识别时临时向服务端发送图片，图片和分类结果保存在本机素材库。
2. 导入后显示本批次处理数和失败数。素材卡片展示已有分类及描述，明确区分已识别、尚无分类结果和识别失败；可识别的错误给出原因。
3. 用户可以逐张重试，也可以选择「重新分析待识别」批量处理。已导入的图片使用本机素材副本，无需重新导入。成功重试清除错误状态，失败保留图片及已有识别结果。
4. 已识别且尚未归档的图片生成分组建议。重新打开素材库时可以基于已保存的结果恢复建议。用户可以修改分组名称、排除图片，或归入已有产品。确认归档后切换到本次归档的产品。
5. 用户可以从归档产品中勾选图片，点击「用所选素材制作视频」，把产品和所选素材带入向导。

**分类空白的修复**。桌面端按实际图片 MIME 类型发送识别请求，并记录服务端逐张返回的错误。前端向分组接口提交素材数组，修复识别成功后仍因请求格式不符而收到 HTTP 422 的问题。

## 3. 本机视频制作向导

| 步骤 | 默认路径 | 可调整项 |
|---|---|---|
| 1. 选择素材 | 带入素材库已选图片。直接进入向导时预选所选产品的可用素材 | 切换产品，逐张勾选或取消 |
| 2. 设置制作参数 | 使用产品名称作为标题、竖屏、每张素材 4 秒、快速分镜 | 修改标题、画幅、素材时长、产品卖点开关；选用智能分镜后可填写创作要求和选择语言 |
| 3. 检查分镜 | 查看生成的镜头，核对画面、原始文件名与文案 | 调整单个镜头时长 |
| 4. 确认渲染 | 核对分辨率和镜头数量。环境就绪时确认开始本机渲染 | 打开环境检测或返回修改分镜；从环境检测返回时保留当前分镜 |
| 5. 查看成片 | 查看渲染状态和进度，完成后预览成片 | 下载成片 |

快速分镜使用模板。智能分镜由用户选择，依赖服务端已配置的视频规划模型；模型根据所选素材的类别、标签和描述选图和排镜。该规划请求使用素材元数据，渲染时桌面端读取本机素材文件。

## 4. 实现落点

| 位置 | 职责 |
|---|---|
| `desktop/src/library_store.go` | 本机素材库存储：本地素材副本 + 本地索引（按用户隔离），提供列表、归档分组、复制到渲染目录等原语 |
| `desktop/src/library_bridge.go` | Wails 桥：目录选择、导入、逐张识别、重新分析待识别、归档分组等动作，并负责「识别时临时把字节发给服务端」 |
| `desktop/src/library_render.go` | 本机渲染编排与结果产出 |
| `dashboard/src/pages/LocalLibrary/` | 本机素材库页面（导入、识别状态、分组复核、归档） |
| `dashboard/src/pages/LocalVideoWizard/` | 本机视频向导（五步） |
| `dashboard/src/api/localLibrary.ts` | 前端 ↔ 桌面桥的调用封装 |
| `desktop/src/library_store_test.go`、`desktop/src/library_bridge_test.go` | 桌面桥与本机存储的定向测试 |

识别推理位置不变：仍是**服务端调用远程多模态模型**，客户端不跑模型；本机保存素材本体与分类结果（决策见 [平台 PRD §3.7](../../PRD.md)）。

## 5. 验收标准与验证记录

1. 桌面左栏可直接打开三个入口，并突出当前页面。
2. 导入一批图片后，识别成功的图片显示分类并进入待核对分组；失败的图片保留在本机并显示状态和重试入口。
3. 对此前未出现分类结果的 10 张已保存图片执行「重新分析待识别」。识别结果写回原素材记录，成功项可生成分组并确认归档。
4. 确认归档后可看到对应产品和素材。勾选图片进入向导后，所选图片保持选中。
5. 使用默认参数可以走完五步。进入环境检测并返回后，已确认的素材和分镜仍在当前会话中。
6. 智能分镜仅从本次选中的候选素材取图。确认后使用本机素材渲染，并在完成时展示预览和下载入口。

本会话通过了前端构建、侧栏和素材 API 定向测试、后端识别与分镜定向测试，以及桌面桥接定向测试。浏览器使用隔离样本验证了重新分析、确认归档、选图、环境检测返回和成片预览。原有 10 张图片、真实模型和实际渲染仍需在更新后的桌面客户端验收。

## 6. 非目标

- 不改变服务端产品素材库（Web 路径）的归属与流程，见 [平台 PRD §3.7](../../PRD.md)。
- 不在桌面端本地跑模型：识别仍由服务端调用远程多模态模型完成。
- 不引入在线渲染服务或服务端视频渲染队列。
- 不在客户端实现多轨剪辑；多平台批量输出属于 [工作台升级 PRD](./PRD.md) 的范围。
